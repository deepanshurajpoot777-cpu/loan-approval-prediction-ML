# loan-approval-prediction-ML
A Machine Learning classification project that predicts whether a loan application will be approved based on applicant details using Logistic Regression
# Loan Approval Prediction using Machine Learning

# Project Overview
This project predicts whether a loan application will be approved using Machine Learning. It is developed using Python and Scikit-learn with the Logistic Regression algorithm.

# Features
- Data Loading and Exploration
- Data Preprocessing
- Label Encoding
- One-Hot Encoding
- Feature Scaling
- Logistic Regression Model
- Model Evaluation
- Confusion Matrix Visualization
- Classification Report
- Accuracy Score
- User Loan Approval Prediction

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

# Dataset Features
- Person Age
- Gender
- Education
- Income
- Employment Experience
- Home Ownership
- Loan Amount
- Loan Intent
- Loan Interest Rate
- Loan Percent Income
- Credit History Length
- Credit Score
- Previous Loan Defaults
- Loan Status (Target)

# Machine Learning Algorithm
- Logistic Regression

# Model Evaluation
- Accuracy Score
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Classification Report
